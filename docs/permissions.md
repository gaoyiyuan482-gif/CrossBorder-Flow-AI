后端额外执行：

- Maker 不能批准自己制作的付款。
- 账户冲突未提供有效核实证据时，直接调用 API 也不能批准。
- Rejected 付款不能提交银行。
- Demo Admin 只能加载合成场景，不能模拟普通银行事件。
- AI provider 没有任何审批、账号修改或银行状态写入权限。
