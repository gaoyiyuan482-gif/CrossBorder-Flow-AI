# 威胁模型与 V1 边界

| 风险 | PoC 控制 | 生产环境仍需 |
|---|---|---|
| 未授权审批 | 后端 RBAC、Maker/Approver 分离、拒绝审计 | 企业 IAM、权限目录、加强认证 |
| 收款账号篡改 | 保留发票/ERP 原始字段；AI 与 UI 都不能改账号 | 可信联系方式、签名主数据变更 |
| 重复/乱序银行事件 | 唯一 event ID、来源与状态顺序校验 | 签名 webhook、重放窗口、队列 |
| 审计被修改 | 应用层追加式 `audit_entries_v2` | WORM/SIEM、保留策略和监控 |
| 多访客互相覆盖 | 浏览器 session 隔离 D1 记录 | 正式租户与用户身份边界 |
| 恶意文件 | V1 只读取仓库内文本 fixture | 病毒扫描、沙箱 OCR、大小限制、PII 控制 |
| AI 幻觉或中断 | 账户比较不用 AI；AI 失败不能绕过规则 | 模型评测、监控、内容安全与降级策略 |

本项目不是安全审查后的支付系统，不得处理真实客户或银行数据。
